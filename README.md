# SecurityCheck Web Parser

Web based parser for SecurityCheck by glax24 & Severnyj that converts outdated software listed in logs into a forum ready response

This tool is based on **rifteyy's** [`parse_securitycheck`](https://github.com/rifteyy/parse_securitycheck), ported to JavaScript to run directly in the browser

## How It Works

1. Upload a **SecurityCheck** log
2. The parser identifies outdated software, potentially unwanted programs, remote desktop software, and so on
3. Copy the generated forum formatted response ready for use
